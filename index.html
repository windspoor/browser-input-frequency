A callback may contain several coalesced samples. Each row is independent; never add their counts together. “Observed” does not establish sample completeness or certify a device’s USB polling rate.

01 / DELIVERY

Callbacks aren’t samples.

A browser can group movement updates into one callback. Pointer Events can expose those updates through getCoalescedEvents(). This experiment counts the children or the parent, never both.

02 / PRECISION

No universal 1,000 Hz ceiling.

Delivery depends on the browser, operating system and device. Raw updates can expose more frequent input, but cannot recover samples lost upstream. Coarse timestamps can make interval statistics unavailable.
